MistyVPN for Linux

Version 0.1.6. Install or update with one command:

curl -fsSL https://packages.mistyvpn.com/install.sh | sudo sh

Then misty login and misty connect. misty help explains the rest.

Ubuntu and Debian get our signed apt repository, so sudo apt upgrade keeps it up to date. Other distributions: sudo misty update.
